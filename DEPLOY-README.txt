OMNITECH CORE — PAQUETE WEB REDISEÑADO

Contenido: sitio estático completo basado en el ZIP de referencia, con páginas de módulos, demo, páginas legales, estilos y JavaScript.

Cambios comerciales aplicados:
- Prueba de 7 días (no 14).
- Una única oferta pública: aplicación a medida desde 149 €/mes.
- El precio final depende de módulos, integraciones y configuración.
- No se publicitan planes cerrados ni descuentos anuales.
- El formulario envía una solicitud de lead al endpoint existente y comunica revisión comercial manual. No crea workspaces, cuentas, licencias, módulos ni contrataciones automáticamente.

Deploy Vercel:
1. Descomprime este paquete en la raíz del proyecto web.
2. Comprueba que index.html queda en la raíz.
3. Framework preset: Other / Static. Build command vacío. Output directory: . (raíz).
4. Despliega a Preview primero y valida formularios, rutas y versión móvil.
5. Promociona a Production cuando la revisión sea satisfactoria.

Nota de alcance: el ZIP original no incluye imágenes/archivos de Ava ni una referencia visual de ella; por tanto, este paquete conserva fielmente el contenido y la estructura que sí estaban en el ZIP, pero no puede recuperar un avatar que no venía incluido.
